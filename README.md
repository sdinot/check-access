# check-access

This is a temporary project aimed at testing the possibilities for interaction
on GitHub between public accounts and EMU (Enterprise Managed Users) accounts,
as well as the email addresses that can be used within my company.

In addition, I'd like to check if I can push source code to this repository
using an author and committer identity whose email address isn't one of those
associated with my GitHub account.
